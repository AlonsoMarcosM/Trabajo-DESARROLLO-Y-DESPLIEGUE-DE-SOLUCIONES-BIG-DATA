# Documentación del proyecto

Estructura creada para organizar entregas por hitos y fuentes documentales.

## Estructura

- `fuentes/pdf/`: PDFs originales de referencia.
- `fuentes/md/`: conversión a Markdown de las fuentes y guía docente reescrita.
- `hito_1/`: memoria completa de alcance y viabilidad (`.md` y `.tex`).
- `hito_2/`: plantilla de memoria (`.md` y `.tex`).
- `hito_3/`: plantilla de memoria (`.md` y `.tex`).
- `hito_4/`: plantilla de memoria (`.md` y `.tex`).

## Conversión de PDFs a Markdown

Script disponible en `scripts/pdf_to_markdown.py`.

Ejemplo de ejecución:

```bash
python scripts/pdf_to_markdown.py --input-dir documentacion/fuentes/pdf --output-dir documentacion/fuentes/md
```
