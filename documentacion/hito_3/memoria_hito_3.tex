\section*{Resumen tecnico validado}

El ciclo de modelado se ha ejecutado en Databricks mediante el job
\texttt{telco\_churn\_ml\_orchestration}, con run validado
\texttt{329240873651157} en estado \texttt{SUCCESS}. El dataset de entrenamiento
\texttt{workspace.telco\_churn.gold\_churn\_training\_dataset} contiene
16.316.445 filas y cubre la ventana temporal 2023-07-01 a 2024-12-01.

La experimentacion MLflow ejecuto ocho configuraciones de regresion logistica.
La mejor configuracion fue \texttt{reg\_param=0.01},
\texttt{elastic\_net\_param=0.5} y \texttt{max\_iter=100}, con AUC-PR de
validacion 0.990393 y umbral 0.64. El modelo registrado es
\texttt{workspace.telco\_churn.churn\_lr\_pipeline}.

Tras la evaluacion champion-challenger, el alias \texttt{champion} permanece en
la version 2 y la version 3 queda marcada como \texttt{rejected}, porque no
mejora estrictamente el AUC-PR de test del champion. La tabla baseline de test es
\texttt{workspace.telco\_churn.gold\_churn\_test\_baseline}.
