\section{Objetivo del hito}
El objetivo de este hito es construir una base de datos fiable para modelado, resolviendo carga, validación, trazabilidad y preparación de tablas para entrenamiento.

\section{Alcance técnico}
El trabajo se organiza en cuatro bloques: entorno colaborativo en Databricks, ingesta en bronze, calidad en silver y construcción de features en gold. La ejecución se mantiene en modo batch para controlar complejidad y coste.

\section{Diseño de datos previsto}
\subsection{Capa bronze}
Conservación del dato en bruto con metadatos de auditoría (ingestión, origen y registros rescatados por errores de esquema).

\subsection{Capa silver}
Aplicación de reglas de calidad (nulos, rangos, tipos y coherencia temporal) y envío de anomalías a cuarentena para análisis.

\subsection{Capa gold}
Construcción de variables dinámicas y estáticas para generar una tabla base de modelado para el Hito 3.

\section{Plan de ejecución}
\begin{itemize}
  \item Semana 1: entorno, permisos, estructura de trabajo y primera carga.
  \item Semana 2: reglas de calidad y cuarentena.
  \item Semana 3: tablas gold y validación final.
\end{itemize}

Reparto en pareja: Alonso en pipeline y trazabilidad; Jose en calidad de datos y validación de variables; decisiones y memoria en conjunto.

\section{Riesgos y mitigación}
\begin{itemize}
  \item Esquemas inestables: validaciones tempranas y versionado.
  \item Falta de cobertura de variables: análisis de completitud antes de cerrar gold.
  \item Retraso de integración: priorización de MVP completo y ampliación incremental.
\end{itemize}

\section{Resultado esperado}
Al cierre del hito debe existir un pipeline ejecutable, tablas documentadas y dataset consistente para entrenamiento del modelo de churn.
